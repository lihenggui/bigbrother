Big Brother는 root 권한이 있는 Android 기기에서 앱이 공유 저장공간의 파일을 열거나, 기기 식별자를 읽거나, 시스템에 비공개 데이터를 요청할 때 이를 기록합니다. 센서를 사용한 시간대와 카메라, 마이크, 위치 등 민감한 권한의 사용 내역도 기록합니다.

접근 기록을 앱별 또는 시간대별로 볼 수 있습니다. 앱, 파일 이름 또는 데이터 유형으로 검색할 수 있습니다. Big Brother는 네트워크에 접속할 수 없습니다. 기록은 기기에 최대 30일 동안 보관됩니다.

‘감옥’은 격리된 앱이 무엇에 접근할 수 있는지 제어합니다. 격리된 모든 앱에 공통 규칙을 설정하거나 특정 앱에 별도 규칙을 적용할 수 있습니다. ‘감옥’은 새로 설치된 앱을 자동으로 격리하고, 앱의 네트워크 접속을 차단하고, 접속 대상을 기록하고, 선택한 대상을 차단할 수 있습니다.

Big Brother에는 root 권한, Android 12 이상, BTF를 지원하는 GKI 2.0 커널(5.10 이상)이 필요합니다. arm64 및 x86_64 기기에서 작동합니다. x86_64에서는 64비트 앱의 접근만 기록합니다.

선택 사항인 LSPosed 후크(Xposed API 101 이상)는 콘텐츠 제공자를 통한 접근을 기록합니다. 연락처나 문자 메시지 등을 조회하면 어떤 데이터 모음이 조회되었는지 기록합니다. ‘감옥’은 ‘시스템 프레임워크’ 범위를 사용해 Android ID, 광고 ID, 설치된 앱의 표시 범위, 시스템 파일 선택기에서 부여되는 파일 접근 권한을 관리합니다.
